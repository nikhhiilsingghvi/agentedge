01 / 06 · ICLR 2024
AutoGen: Enabling Next-Gen LLM Applications via Multi-Agent Conversation
Wu et al. · ICLR Workshop on LLM Agents
Multi-Agent · Cloud Framework
  • Conversation programming paradigm — agents as stateful message-passing entities
  • Role separation: planner ≠ executor ≠ verifier inspires our 5-phase loop
  • Flexible interaction patterns gave us the Perceive→Plan→Execute→Verify→Recover blueprint
  • Unified infrastructure concept shaped our modular Python architecture

AutoGen taught us how to structure agent conversations — AgentEdge applies this on constrained hardware with real sensor tool-use that AutoGen never addressed.

02 / 06 · ICLR 2023
ReAct: Synergizing Reasoning and Acting in Language Models
Yao et al. · Princeton / Google Brain
Agentic Loop · Reasoning
  • Thought→Action→Observation as atomic unit — sensors are our “observation”
  • Interleaved reasoning traces reduce hallucination — inspires our structured JSON plan format
  • Tool-use grounding: external feedback loops back into reasoning
  • Core justification for our Perceive→Plan→Execute loop design

ReAct gave us the Thought-Action-Observation loop — we applied it to physical embedded control with real sensor grounding in a domain ReAct never targeted.

Three Novel Contributions

Filling the Gap
1
Novel Contribution #1
Resource-Adaptive Task Decomposition (RAD)
Monitors live RAM and CPU before every plan step. When resource state reaches CRITICAL, automatically splits agent plan steps into sub-tasks at runtime — preventing OOM failures on embedded hardware. No existing paper implements this.
Fills gap in AutoGenExtends Rüb & GerhardsBeyond ATLASv2Operationalizes Qin et al.
2
Novel Contribution #2
Embedded Sensor Failure Recovery Protocol
Formal 4-type failure taxonomy: TIMEOUT, BAD_DATA, DISCONNECT, BUS_ERROR. Criticality-based recovery matrix: RETRY / SUBSTITUTE / SKIP / ABORT. Verified in session A2ED2A27: 50% success rate (1 RETRY→SUCCESS, 1 SKIP→PARTIAL).
Fills gap in AutoGenExtends ReAct tool-useMissing from ATLASv2Not in Qin et al.
3
Novel Contribution #3
AgentEdge-Bench: 20-Task Embedded Benchmark
First standardized benchmark for evaluating agentic AI on embedded hardware with physical sensor tool-use. 20 tasks across 4 categories: Normal, Single Fault, Multi-Fault, Recovery. All existing benchmarks (HotpotQA, ALFWorld) are text/virtual only.
Fills gap in Belcak et al.No equivalent in RübExtends ReAct benchmarksFirst embedded standard
📢 One-Line Claim — For IEEE Paper Related Work Section

“None of the above works address the combination of: (a) real sensor tool-use, (b) runtime resource adaptation via RAD, (c) formal sensor failure recovery with a 4-type taxonomy, and (d) a standardized embedded agentic benchmark — which is exactly the gap AgentEdge fills.”
